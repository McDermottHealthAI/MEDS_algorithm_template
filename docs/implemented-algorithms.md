# Implemented algorithms

The [algorithm catalogue](https://mcdermotthealthai.github.io/meds-algorithm/implemented-algorithms/)
is maintained in `meds-algorithm`, the shared ecosystem repository. It includes implementation status,
declared profiles, validation evidence and reviewed PyPI installation commands.

To register an implementation or update its reviewed version, open a PR editing
[`catalogue/algorithms.yaml`](https://github.com/McDermottHealthAI/meds-algorithm/blob/main/catalogue/algorithms.yaml)
there. The [catalogue guide](https://mcdermotthealthai.github.io/meds-algorithm/implemented-algorithms/#register-or-update-an-algorithm)
explains evidence requirements, private listings and automated release observations.

The template provides generation, implementation and publishing instructions; it does not keep a second
registry or update workflow. See [publishing an algorithm](publishing-algorithms.md) for preparing a release
before registering its PyPI version.
